# PM-18 — крепёж и стыки

## Метод

Для каждого из 360 размещённых экземпляров по мировым координатам и
кватерниону строится ось крепежа, и определяется, **через какие детали
она проходит**. Соседство деталью-стыком не считается: фиксируется
именно пересечение оси с коробкой детали.

## FACT — конфирмат: 28 штук

| Стык | Детали | Ориентация | Количество |
| --- | --- | --- | --- |
| крыша ↔ стенка левая | накладной горизонт / вертикаль | вертикальная | **2** |
| крыша ↔ стенка правая | | вертикальная | **2** |
| крыша ↔ перегородка 1 | | вертикальная | **2** |
| дно ↔ стенка левая | | вертикальная | **2** |
| дно ↔ стенка правая | | вертикальная | **2** |
| дно ↔ перегородка 1 | | вертикальная | **2** |
| **итого корпус** | | | **12** |
| ящик.зад ↔ ящик.лево | короб ящика | горизонтальная | 2 × 4 ящика = 8 |
| ящик.зад ↔ ящик.право | короб ящика | горизонтальная | 2 × 4 ящика = 8 |
| **итого ящики** | | | **16** |
| **ВСЕГО** | | | **28** |

**В этом изделии конфирмат применяется только на двух видах стыка:**
накладной горизонт к вертикали корпуса и задняя стенка короба к его
боковинам. **По 2 на стык**, без исключений.

## FACT — рафикс: 48 штук (+ 48 штоков)

| Стык | Количество |
| --- | --- |
| перегородка 1 ↔ полка-стяжка | 8 |
| полка-стяжка ↔ стенка левая | 4 |
| полка-стяжка ↔ стенка правая | 4 |
| доп. перегородка ↔ полка / полка-стяжка | 24 |
| доп. перегородка ↔ крыша / дно | 6 |
| доп. перегородка (8) ↔ полка-стяжка | 2 |
| **ВСЕГО** | **48** |

Штоки рафикса (48) стоят в тех же стыках — **пара «рафикс + шток» на
каждое соединение подтверждена пространственно**, а не только
соотношением 1:1 (§6B).

**Рафикс не встречается ни на одном стыке «накладной горизонт ↔
вертикаль корпуса».** Эти стыки целиком отданы конфирмату.

## §6A / §6B / §6C — проверка парности

| Проверка | Результат |
| --- | --- |
| Рафикс ↔ шток рафикса | **подтверждено пространственно**: 48 пар в одних и тех же стыках |
| Минификс ↔ его шток (дюбель) | **НЕ подтверждено**: все 40 дюбелей в позиции-заглушке, координат нет |
| Минификс ↔ заглушка | **НЕ подтверждено**: 40 заглушек без координат |
| Конфирмат ↔ заглушка | **НЕ подтверждено**: 28 заглушек без координат |
| Конфирмат проходит через две детали | **подтверждено**: ось пересекает ровно две конструктивные детали во всех 28 случаях |

Соотношение 1:1 у заглушек и дюбелей остаётся **арифметическим**, как и
было: пространственного доказательства пары файл не даёт (§6A требует
именно этого различения).

## §7 — классификация результата

### OUTCOME B — расстановка подтверждена, универсальное правило нет

Подтверждено:

* какие виды стыков в **этом** изделии получают какую систему;
* сколько крепежа на каждый стык **в этом изделии**;
* что три системы сосуществуют не «вообще», а по чётко разделённым
  областям: конфирмат — накладные горизонты и короб ящика, рафикс —
  полки и перегородки, минификс — только ящики.

Исключено (важнее подтверждённого):

| Гипотеза | Опровергнута чем |
| --- | --- |
| «Система выбирается на весь проект» | в одном изделии три системы одновременно, по разным стыкам |
| «Тип стыка не влияет на систему» | влияет строго: ни один накладной горизонт не получил рафикс, ни один минификс не попал в корпус |
| «Количество на стык одинаково для всех систем» | конфирмат 2, рафикс 2 (рафикс + шток), минификс 10 на ящик |

НЕ подтверждено:

| Что | Почему |
| --- | --- |
| зависит ли выбор системы от длины стыка | одно изделие, длины стыков почти не варьируются |
| зависит ли от материала и толщины | всё ЛДСП 16 мм |
| правило для стыков, которых в изделии нет | дверей, цоколя, столешницы здесь нет |
| универсальность «2 на стык» | 596-миллиметровая полка и 1240-миллиметровый горизонт получили одинаково по 2 — но это один размер каждого вида |

**Implementation allowed: NO.** Одно изделие даёт расстановку, а не
алгоритм.

«11 точек на 1236 мм» нечем.

## §9 — два уровня результата

### Placement evidence (подтверждено)

* гвозди идут **и по внешнему контуру, и по линиям полок**;
* горизонтальные линии получают точку на каждой вертикали корпуса;
* вертикальные края получают 3 точки: верх, середина, низ;
* 24 гвоздя на панель при данных размерах;
* 5 гвоздей и все 32 крабика в спецификации есть, в модели не размещены.

### General rule (НЕ подтверждено)

* шаг 100 мм как правило — не отделим от «11 точек на 1236 мм»;
* поведение при другой ширине панели неизвестно;
* поведение при другом числе перегородок неизвестно;
* распределение крабиков неизвестно в принципе;
* правило для панели 1836 × 628 из второго изделия проверить нечем —
  спецификации фурнитуры для него нет.

**Implementation allowed: NO.**

## Главный вывод для архитектуры

Ранее было доказано, что модель «один `jointType` на проект → один вид
фурнитуры» недостаточна. Теперь известно **чем именно** её заменять:

```
Стык (две детали + вид стыка)
   → Система соединения        (конфирмат / рафикс / минификс / шкант)
      → Компоненты             (основной + ответный + заглушка)
```

Файл показывает, что выбор системы зависит **от вида стыка**, а не от
проекта: накладной горизонт к вертикали — конфирмат, полка к вертикали —
рафикс, детали ящика — минификс.

Это подтверждает **форму** модели. Значения — какой стык какую систему
получает в общем случае — по-прежнему требуют второго изделия с другим
набором стыков.

**Минимальный источник, который разблокирует следующий шаг:** `.b3d`
ещё одного изделия — желательно с распашными дверями (даст `PM-06`) и
другой шириной задней стенки (различит модели PM-17).
