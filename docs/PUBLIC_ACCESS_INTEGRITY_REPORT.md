## Треугольник согласованности

```
ссылка в README  =  вычисленный адрес площадки  =  адрес из вывода выкладки
```

Первую пару сверяет `check:public` без сети, на каждом pull request.
Вторую — шаг в задаче `smoke`, когда фактический адрес уже известен.

Расхождение любой пары роняет прогон. Ни `continue-on-error`, ни
`|| true`, ни автоматической правки README: смена публичного адреса —
решение человека, а не опечатка скрипта.

## Что охрана не покрывает

1. **Доступность площадки на pull request.** Намеренно: проверка не
   должна краснеть оттого, что у GitHub Pages неполадки. Живой адрес
   проверяет `smoke` после выкладки.
2. **Отложенные чанки статически.** Vite вычисляет их адреса
   относительно модуля, поэтому базовый путь на них не влияет.
   Подтверждается прогоном E2E по подкаталожной сборке, где они
   действительно загружаются.
3. **Собственный домен.** Если его подключат, вычисленный адрес
   перестанет совпадать с фактическим, и проверка упадёт — верно по
   смыслу, но потребует записать новый источник истины явно. Сегодня
   домена нет.
