# Motion System

Движение в мебельном конструкторе служит пониманию: что я схватил, куда это
поедет, откуда взялась эта панель, где предел. Движение ради красоты не добавляется.

Основание — `apple-design` skill (`d23d7f88`), раздел о пружинах, передаче
скорости, проекции момента и прерываемости.

---

## 1. МОДЕЛЬ

Пружины, а не длительности. Два понятных параметра вместо трёх физических:

| Параметр | Смысл |
| --- | --- |
| **response** | за сколько секунд значение практически доходит до цели. Не «длительность» — у пружины её нет |
| **damping** | перерегулирование. `1.0` — критическое затухание, без отскока. `< 1.0` — отскок |

Правило проекта:

> **damping = 1.0 по умолчанию. Отскок — только если жесту предшествовал импульс
> (бросок, флик, отпускание с ненулевой скоростью).**

Панель, которая просто открылась по клику, отскакивать не должна.
Карточка, которую бросили, — должна.

## 2. ТОКЕНЫ

```ts
export const spring = {
  /** Мгновенная микрореакция: нажатие, hover-масштаб. */
  instant:  { damping: 1.0,  response: 0.15 },

  /** База интерфейса: панели, переезд активной вкладки, раскрытие секции. */
  ui:       { damping: 1.0,  response: 0.32 },

  /** Перемещение объекта в пространстве, доводка после drag. */
  move:     { damping: 1.0,  response: 0.40 },

  /** Sheet и drawer. */
  sheet:    { damping: 0.85, response: 0.30 },

  /** Импульс: бросок в планировщике, возврат карточки в палитру. */
  momentum: { damping: 0.80, response: 0.38 },

  /** Резиновый возврат viewport к границе. */
  rubber:   { damping: 1.0,  response: 0.28 },
} as const;
```

Значения `ui` и `move` соответствуют ориентиру задания
(`damping ≈ 1.0`, `response ≈ 0.3–0.4`) и таблице skill
(перемещение `1.0 / 0.4`, sheet `0.8 / 0.3`).

### 2.1 Не-пружинные переходы

Для не-жестовых изменений цвета и прозрачности пружина избыточна:

```ts
export const ease = {
  color:   { duration: 120, curve: 'cubic-bezier(.2,0,.2,1)' },   // hover, press
  fade:    { duration: 180, curve: 'cubic-bezier(.2,0,.2,1)' },
  theme:   { duration: 180, curve: 'cubic-bezier(.4,0,.2,1)' },   // смена темы
};
```

`transition` и `@keyframes` **запрещены** для всего, что можно схватить пальцем.
Их нельзя перехватить и развернуть по текущему значению.

## 3. КАРТА ДВИЖЕНИЙ

| Взаимодействие | Токен | Свойство | Примечание |
| --- | --- | --- | --- |
| Нажатие кнопки | `instant` | `scale` 1 → 0.97 | на pointerdown |
| Отпускание | `instant` | `scale` → 1 | |
| Hover-фон | `ease.color` | `background` | без пружины, без задержки |
| Переезд активной вкладки | `ui` | `x`, `width` | пилюля едет, а не мигает |
| Раскрытие панели свойств | `ui` | `scale`, `x/y`, `opacity`, `blur` | origin — выбранный объект |
| Закрытие панели | `ui` | обратный путь | зеркально |
| Sheet: открытие | `sheet` | `y` | |
| Sheet: перетаскивание | — | `y` 1:1 | без анимации, прямое следование |
| Sheet: отпускание | `sheet` + velocity | `y` | цель по знаку скорости и проекции |
| Drag полки/разделителя | — | `transform` 1:1 | движение = указатель, без сглаживания |
| Доводка после drag к привязке | `move` + velocity | `transform` | если привязка ближе 6 px |
| Бросок в планировщике | `momentum` + velocity | `x`, `z` | посадка по проекции момента |
| Возврат карточки в палитру | `momentum` + velocity | `x`, `y` | |
| Резиновый возврат viewport | `rubber` | `tx`, `ty`, `scale` | |
| Появление тоста | `ui` | `y`, `opacity` | снизу, уход туда же |
| Затемнение под модальным | `ease.fade` | `opacity` | |
| Подсветка проблемы | `ease.fade` | `opacity` контура | без пульсации |
| Смена темы | `ease.theme` | `background`, `color` | без резкого скачка яркости |
| Появление детали в схеме после пересчёта | — | без анимации | схема должна быть точной, не «оживать» |

**Отдельно.** Пересчитанная геометрия не анимируется. Если полка переехала
из-за изменения габарита — она просто там, где рассчитана. Анимация здесь
создавала бы ложное ощущение движения физического объекта.
Исключение — превью во время drag габарита: там движение непрерывно потому,
что непрерывен сам жест.

## 4. ПЕРЕДАЧА СКОРОСТИ

Между drag и анимацией не должно быть шва.

```ts
const v = medianVelocity(history);   // px/s, медиана по 5 последним сэмплам
animate(el, { y: target }, { type: 'spring', ...spring.momentum, velocity: v });
```

Медиана, а не последняя дельта: последняя дельта на отпускании часто нулевая
(палец остановился до подъёма) или шумная, и объект «залипает» либо «выстреливает».

Для API, требующих относительной скорости:

```
relativeVelocity = gestureVelocity / (target − current)
```

Правило `target − current → 0`: если остаток меньше 0.5 px, скорость не
нормализуется, значение ставится напрямую — иначе деление даёт бесконечность.

## 5. ПРОЕКЦИЯ МОМЕНТА

Цель выбирается по спроецированной точке остановки, а не по точке отпускания:

```ts
function project(v: number, decelerationRate = 0.998): number {
  return (v / 1000) * decelerationRate / (1 - decelerationRate);
}

const projected = current + project(releaseVelocity);
const target = nearestSnapPoint(projected);
animate(el, { x: target }, { type: 'spring', ...spring.momentum, velocity: releaseVelocity });
```

Применяется: sheet (открыть/закрыть), планировщик (посадка предмета),
возврат карточки палитры, инерция панорамы схемы.

**Не применяется** к разделителям, полкам и габаритам: там значение —
производственный размер, и «доброс» по инерции означал бы, что пользователь
получил не тот размер, который отпустил.

Решение «открыть или закрыть» sheet принимается **по знаку скорости**, а не по
позиции: медленно оттянутый на 80 % и отпущенный вниз sheet должен закрыться.

## 6. ПРЕРЫВАЕМОСТЬ

Обязательные свойства реализации:

1. Новая анимация читает **текущее визуальное значение** из движка пружины,
   а не логическую цель.
2. При развороте цели скорость переносится, а не обнуляется — иначе на реверсе
   ощущается «кирпичная стена».
3. Движение по X и Y — две независимые пружины. Одна пружина на 2D-дистанцию
   рассинхронизируется, когда по осям разные скорости.
4. Ни один слой не выставляет `pointer-events: none` во время анимации.
5. Закрывающуюся панель можно схватить и вернуть — она подхватывается с текущего
   места и текущей скорости.

Тест приёмки: схватить sheet в середине закрытия и потянуть вверх.
Видимого рывка быть не должно.

## 7. КАДРЫ

- Анимируются только `transform` и `opacity`. `width`, `height`, `top`, `left`
  в анимациях запрещены.
- `will-change` ставится на `pointerdown` и снимается на `pointerup` —
  постоянный `will-change` расходует память впустую.
- Во время drag React не перерисовывается: значения пишутся прямо в
  `element.style.transform` из `rAF`-цикла.
- Чтение геометрии DOM (`getBoundingClientRect`) — один раз на `pointerdown`,
  не в цикле движения. Чередование чтения и записи в одном кадре вызывает
  принудительный reflow.
- Бюджет кадра 16 мс. Превышение — дефект.

## 8. REDUCED MOTION

`prefers-reduced-motion: reduce` означает не «без обратной связи»,
а «без вестибулярной нагрузки».

| Обычно | При reduced motion |
| --- | --- |
| Пружинное открытие панели | кроссфейд 150 мс, без смещения и масштаба |
| Sheet выезжает снизу | появление на месте с кроссфейдом |
| Отскок, инерция, проекция | отключены полностью |
| Резиновость границ | жёсткий стоп |
| Переезд активной вкладки | мгновенная смена фона |
| Тост «выезжает» | появляется на месте |
| **Drag 1:1** | **сохраняется** — это не анимация, а прямое управление |
| Подсветка нажатия | сохраняется |

Реализация — не разбросанные медиазапросы, а один хук:

```ts
const reduced = usePrefersReducedMotion();
const cfg = reduced ? { duration: 0.15, type: 'tween' } : { type: 'spring', ...spring.ui };
```

Так невозможно забыть про настройку в отдельном компоненте.

Дополнительно (по skill): нет полноэкранных движущихся фонов, нет медленных
циклических колебаний около 0.2 Гц, смена темы плавная.

## 9. ВИБРАЦИЯ И ЗВУК

- Звука в приложении нет: это рабочий инструмент, часто используемый рядом с другими.
- Вибрация — только при поддержке устройства и только на реальных событиях:
  срабатывание привязки (10 мс), достижение предела (20 мс), завершение экспорта (15 мс).
- Вибрация, визуальный отклик и изменение значения происходят **в одном кадре**.
  Рассинхронизация разрушает ощущение причинности.
- Отключается в настройках.
