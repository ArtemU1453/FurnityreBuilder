# Next Development Roadmap

PROMPT 51 §15. Порядок следующего этапа, построенный **из
подтверждённых пробелов** (`PRODUCT_GAP_REGISTER.md`), а не из
представлений о том, что было бы хорошо добавить.

Сроков здесь нет намеренно: назначать их, не начав работу, значит
выдумывать.

## Порядок и почему он такой

```
Release blocker        → нет ни одного
        ↓
Core product gap       → PHASE 1
        ↓
Partial implementation → PHASE 2
        ↓
High-value enhancement → PHASE 3
        ↓
Optional future        → PHASE 4
```

Внутри фазы порядок — по влиянию на пользователя, а не по трудоёмкости.

## PHASE 3 — ценные улучшения

### 3.1 Инструмент контура помещения (P-08)

Модель произвольный контур выражает — не хватает рисования. Риск
низкий: планировщик изолирован.

### 3.2 Общее правило разрушающих действий

Из `ACCEPTANCE_GAP_REGISTER.md`, G-04. Сейчас закрыт только один путь —
сетка. Правило «действие, заменяющее дерево, обязано назвать потерю»
стоит сделать одним механизмом, а не повторять от случая к случаю.

### 3.3 Проверка возможно неиспользуемых экспортов

37 кандидатов (`PRODUCT_GAP_REGISTER.md`, §7). По одному символу:
убрать, прогнать типы и тесты, вернуть при падении. Не удалять списком.

## PHASE 4 — необязательное будущее

| Пункт | Почему сюда |
| --- | --- |
| Фасады купе, складные, подъёмные (P-07) | отдельная система направляющих; прямо заявлены как не поддерживаемые |
| Фасад на несколько ячеек | требует пересмотра связи «фасад ↔ ячейка» |
| Обувной модуль, другие типовые наполнения | правила не подтверждены |
| Экспорт CSV | продукт его не заявляет; спроса не зафиксировано |

## Чего в дорожной карте нет и не будет

Серверная часть, учётные записи, регистрация, подписки, оплата, реклама,
аналитика, синхронизация через облако, внешние API. Это не «пока нет» —
это продуктовое решение, закреплённое проверкой `npm run check:brand`,
которая роняет сборку при первом же внешнем обращении.

## Правило входа в следующий этап

Прежде чем начинать любой пункт **PHASE 1**, убедиться, что правило
подтверждено источником и записано в `UNKNOWNS.json`. Пункты 1.2 и 1.3
без этого не начинаются вовсе: выдуманное число в присадке дороже
отсутствующей функции — по нему сверлят.
