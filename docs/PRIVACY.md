# Конфиденциальность

PROMPT 32 §15. Документ описывает, что приложение делает с данными на
самом деле. Каждое утверждение ниже либо проверяется автоматически при
сборке, либо указывает файл, в котором его можно прочитать.

**Коротко: серверной части нет. Проекты остаются в вашем браузере и
никуда не отправляются.**

## 1. Какие данные хранятся

| Данные | Что это |
| --- | --- |
| Проекты | Название, габариты, секции, наполнение, фасады, материалы, настройки конструкции и раскроя |
| Помещения | Стены, проёмы, пол, потолок и расстановка изделий |
| Превью | Небольшое изображение проекта для карточки в библиотеке; строится при сохранении |
| Служебное | Дата создания и дата изменения проекта, версия схемы файла |

Данных о человеке приложение не собирает вовсе: ни имени, ни адреса
почты, ни телефона, ни платёжных сведений. Спросить их негде — форм
регистрации в продукте нет.

## 2. Где они хранятся

**В IndexedDB того браузера, в котором вы работаете.** Это хранилище
внутри браузера на вашем устройстве.

Отсюда следует:

- проекты не видны на другом устройстве и в другом браузере;
- они переживают перезагрузку страницы, перезапуск браузера и обновление
  приложения;
- их удаляет очистка данных сайта — как и любые данные сайта;
- в приватном режиме хранилище может быть недоступно; тогда приложение
  прямо говорит «Постоянное хранилище недоступно» и не делает вид, что
  сохранило.

Чтобы перенести проект на другое устройство или сохранить его надолго,
выгрузите его файлом: библиотека → «Экспорт». Файл сохраняется туда, куда
браузер складывает загрузки, и дальше принадлежит только вам.

## 3. Используется ли сервер

**Нет.** Серверной части у продукта не существует. Сервер участвует ровно
в одном: отдаёт файлы приложения при первом открытии — как отдал бы любой
статический сайт. После этого приложение работает без него, в том числе
полностью без сети.

Все расчёты — геометрия, деталировка, фурнитура, раскрой, чертежи, PDF и
XLSX — выполняются на вашем устройстве кодом, который уже загружен в
браузер. Ни один расчёт никуда не отправляется.

## 4. Аналитика, счётчики, реклама

**Нет ни одного.** Ни Google Analytics, ни Яндекс.Метрики, ни любой другой
системы. Ни рекламных сетей, ни пикселей отслеживания, ни встроенных
виджетов, ни `iframe`.

Это не обещание, а проверка сборки: `npm run check:brand` просматривает
все исходники и собранный пакет и **роняет сборку** при первом же внешнем
адресе, счётчике или `iframe`. Выложить версию со счётчиком, не удалив эту
проверку, технически невозможно.

## 5. Cookies

**Не используются.** Приложение не устанавливает ни одной cookie и не
читает их.

Браузерные хранилища используются два, и оба — локальные:

| Хранилище | Что в нём | Отправляется на сервер? |
| --- | --- | --- |
| IndexedDB | Проекты и превью | Нет |
| Cache Storage | Файлы самого приложения, чтобы оно работало без сети | Нет |

Ни то, ни другое не передаётся при запросах — в отличие от cookies,
которые браузер прикладывает к каждому обращению автоматически.

## 6. Отправляются ли проекты наружу

**Нет.** Проект покидает устройство только тогда, когда вы сами его
выгружаете файлом и сами решаете, что с этим файлом делать. Приложение не
загружает проекты никуда и не имеет для этого ни кода, ни адреса.

Импорт работает так же в обратную сторону: выбранный файл читается прямо
в браузере, никуда не пересылается, и проверяется целиком — размер,
корректность JSON, версия схемы, структура, ссылки. Неподходящий файл
отклоняется с объяснением причины.

## 7. Права доступа

Приложение не запрашивает ни камеру, ни микрофон, ни местоположение, ни
уведомления, ни доступ к файловой системе. Единственный контакт с файлами
— диалог выбора файла при импорте и обычное сохранение при экспорте;
оба открываются только по вашему нажатию.

## 8. Установка на устройство

Приложение можно установить как PWA. Установка означает только, что
браузер сохранит его файлы и добавит значок на домашний экран. Новых прав
доступа она не даёт и ничего дополнительно не собирает; данные остаются
там же, где были — в браузере.

Обновление установленного приложения заменяет его код и **не трогает
проекты**: код лежит в Cache Storage, проекты — в IndexedDB, и обновление
второй области не касается. Это проверяется тестом
`tests/e2e/pwa.spec.ts` («обновление приложения не трогает проекты
пользователя»).

## 9. Как убедиться самому

- Откройте инструменты разработчика, вкладку «Сеть», и поработайте с
  приложением: после первой загрузки обращений не будет.
- Отключите сеть — приложение продолжит работать целиком.
- Прочитайте `scripts/check-brand-independence.mjs`: он перечисляет, что
  именно запрещено и как это ищется.
- Исходный код открыт целиком; собрать своё приложение из него можно
  командой `npm run build`.

## 10. Что здесь НЕ утверждается

Документ описывает приложение, а не хостинг. Сайт, на котором приложение
размещено, может вести собственные журналы обращений — как любой
веб-сервер. Приложение об этом ничего не знает и на это не влияет; за
поведение конкретной площадки отвечает тот, кто её настраивал.
