# FR-04 — что дали производственные документы

PROMPT 65 (источники приложены). FR-04 не входил в тройку целей промпта,
но приложенная деталировка содержит **четыре реальных ящика**, и это
закрывает часть неизвестных, которые два предыдущих промпта закрыть не
смогли.

Базовый коммит `20c40d0`. **Продуктовый код не менялся: это документ
доказательств, а не реализации.**

---

Изделие 1240 × 2100 × 400, один вертикальный отсек шириной 596,
**четыре ящика**.

## 2. CONFIRMED — состав короба

**Короб ящика состоит из ЧЕТЫРЁХ деталей: задняя стенка, левая боковина,
правая боковина, дно. Плюс отдельный фасад. Собственной ПЕРЕДНЕЙ стенки
у короба нет.**

Это прямо опровергает то, на что опирался PROMPT 65-A: пересказ страницы
сборки утверждал «две боковины, **передняя** и задняя стенка, фасад и
тонкое дно». Документ показывает, что передней стенки нет — значит
роль `drawer-front` в нашей модели предназначена именно для **фасада**,
а не для внутренней передней панели.

Развилка «три стенки против четырёх», которую PROMPT 65-A не смог
разрешить, **разрешена документом в пользу трёх стенок**.

| Номинал | **350 мм** |

Уровень доказательности — **`L3`** (производитель + серия + типоразмер).
Это первая позиция фурнитуры в проекте, дошедшая до `L3`.

Количество 2 на ящик **совпадает** с тем, что правило `slideRule` уже
считает, — поведение подтверждено источником, менять нечего.

## 4. CONFIRMED EXAMPLE — размеры одного изделия

Арифметика сходится точно и внутренне непротиворечиво:

| Соотношение | Проверка |
| --- | --- |
| Проём 596 → ящик.зад 538 | 596 − 538 = **58** = 2 × 16 (боковины) + 2 × **13** (зазор на сторону) |
| ящик.лево/право длина 369 → ящик.дно глубина 353 | 369 − 353 = **16** — дно доходит до внутренней грани задней стенки |
| ящик.дно ширина 538 = ящик.зад 538 | дно **между** боковинами, не под ними |
| Проём 596 → ящик.фасад 591 | зазор **2.5 мм** на сторону |
| Глубина короба 369 при номинале направляющей 350 | короб **длиннее** номинала на 19 мм |

Боковой зазор **13 мм** на сторону — ровно то значение, к которому
PROMPT 65-A пришёл по данным производителей (12.7 мм, округлённое
отраслью до 13). Теперь оно подтверждено **производственным документом**,
а не пересказом.

> Раздел называется «подтверждённый ПРИМЕР» намеренно. Все числа взяты из
> одного изделия с одной шириной отсека. Что `596 − 2·13 − 2·16 = 538` —
> факт; что это **формула для любой ширины** — из одного примера не
> следует (§1).

## 6. Почему реализация всё ещё не разрешена

Подтверждение **состава** — не подтверждение **формул**. Из одного
изделия известно, каким получился короб при проёме 596 и корпусе
глубиной 400. Неизвестно, как он изменится при других размерах:

| Вопрос | Почему одного примера мало |
| --- | --- |
| Высота боковины 179 при фасаде 196 — разница 17 или доля? | одно наблюдение не различает постоянную и коэффициент |
| Глубина короба 369 при корпусе 400 — минус 31 или «номинал + 19»? | два разных объяснения, одинаковый результат |
| Номинал 350 при корпусе 400 — «глубина − 50» или ближайший из ряда? | не различить |
| Дно 538 × 353 — в паз или снизу? | размеры совпадают для обоих способов |

**Разблокирует минимальный источник:** деталировка изделия с ящиками
**другой глубины корпуса и другой ширины отсека**. Два изделия с разными
размерами превратят каждое «одно наблюдение» выше в проверяемую
зависимость.

Второй по силе вариант — разбор проектного файла `.b3d`: он содержит
координаты (`X`, `Y`, `Z`) поэкземплярно и закрыл бы положение короба по
Y, которое деталировка не даёт в принципе.
