# Чек-лист выкладки в production

PROMPT 36 §7. Что проверить перед каждой выкладкой и сразу после неё.
Отличие от `RELEASE_CHECKLIST.md`: тот отвечает на вопрос «готова ли
версия», этот — «правильно ли она размещена».

Пункт считается пройденным, только если его действительно проверили.
Галочка по памяти — не проверка.

## Источник

- [ ] Рабочее дерево чистое: `git status` пуст
- [ ] Коммит тот, который собираются выкладывать
- [ ] Версия в `package.json` соответствует выпуску
- [ ] В дереве нет отладочных файлов, дампов, временных выгрузок
- [ ] Нет `.env` и файлов с ключами (у продукта переменных окружения нет вовсе)

## Качество

- [ ] `npm ci` с нуля проходит
- [ ] `npm run typecheck`
- [ ] `npm run lint`
- [ ] `npm run test`
- [ ] `npx playwright test --project=chromium`
- [ ] `npx playwright test --project=chromium-dev`
- [ ] `npm run build`

Одной командой первые шесть закрывает `npm run verify`.

## Артефакт

- [ ] `dist/index.html` и `dist/404.html` на месте
- [ ] Чанки `assets/index-*.js` и `assets/index-*.css` на месте
- [ ] Отложенные чанки `assets/pdf-*.js` и `assets/xlsx-*.js` доступны
- [ ] Значки: `favicon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`
- [ ] `manifest.webmanifest` на месте
- [ ] `sw.js` на месте, имя кэша содержит версию
- [ ] Шрифт `fonts/LiberationSans-Regular.ttf` с уведомлением о лицензии
- [ ] Нет карт исходников, тестов, артефактов прогонов
- [ ] Нет ссылок на `localhost` и адреса разработки
- [ ] Базовый путь один и тот же в разметке, манифесте и `sw.js`

Состав и содержимое проверяет `npm run check:release` — он же откажет,
если появится лишний файл или отладочный вывод.

## Хостинг

- [ ] Сборка собрана под **фактический** базовый путь: корень домена —
      `npm run build`, подкаталог — `APP_BASE=/путь/ npm run build`
      (`DEPLOYMENT.md` §2; несовпадение даёт белый экран без сообщения)
- [ ] HTTPS: без него не работают ни офлайн, ни установка
- [ ] SPA-fallback настроен **или** хостинг сам отдаёт `404.html`
- [ ] `index.html` и `sw.js` отдаются с `Cache-Control: no-cache`
- [ ] `/assets/*` отдаются с длинным кэшем
- [ ] `manifest.webmanifest` отдаётся с типом `application/manifest+json`
- [ ] `sw.js` отдаётся с типом `text/javascript`

## Приложение после выкладки

Пройти на боевом адресе, а не на локальной сборке.

- [ ] Открывается: не белый экран, ни одного 404 в сети
- [ ] Консоль чиста: ни ошибок, ни предупреждений, ни битых запросов
- [ ] Создать проект, задать габариты — сцена отвечает
- [ ] Секции, ячейки, полки — число деталей растёт
- [ ] Сохранить, перезагрузить страницу — проект вернулся тем же
- [ ] Производство: детали, раскрой, фурнитура, присадка открываются
- [ ] Экспорт PDF: файл скачивается, открывается, кириллица читается
- [ ] Экспорт XLSX: файл скачивается и открывается
- [ ] Помещение: комната, расстановка, проём — переживают перезагрузку
- [ ] Прямые адреса: `/library`, `/production` и неизвестный путь
      открывают приложение
- [ ] Телефон: 375, 390, 430 — навигация, редактор, сохранение, экспорт
- [ ] Без сети: отключить, перезагрузить — приложение работает

## Обновление версии

Проверяется при выкладке поверх уже работающей версии.

- [ ] Появляется предложение «Доступна новая версия приложения»
- [ ] После нажатия «Обновить» встаёт новая версия
- [ ] Остаётся ровно один кэш приложения — новый
- [ ] Сохранённые проекты на месте
- [ ] Ни одного битого запроса: старый HTML не смешался с новым JS

Автоматически это проверяет `tests/e2e/deploy-update.spec.ts` — он
подменяет содержимое отдаваемого каталога двумя настоящими сборками:

```bash
DEPLOY_LIVE_DIR=<каталог сервера> \
DEPLOY_VER_A=<сборка A> DEPLOY_VER_B=<сборка B> \
PLAYWRIGHT_BASE_URL=<адрес> \
npx playwright test --project=chromium tests/e2e/deploy-update.spec.ts
```

## Проверка развёрнутого приложения тем же набором

Отдельного набора «проверок после выкладки» не заводится: те же
сценарии направляются на боевой адрес.

```bash
PLAYWRIGHT_BASE_URL=https://example.org \
npx playwright test --project=chromium tests/e2e/acceptance.spec.ts
```

Так проверка выкладки не может разойтись с приёмкой: набор один.
