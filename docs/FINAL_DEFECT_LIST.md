# Итоговый список дефектов

PROMPT 31 §27. Всё, что нашёл финальный аудит перед выпуском: и
исправленное, и оставленное с объяснением. Список полный намеренно —
дефект, который решили не чинить, всё равно должен быть виден, иначе
следующий человек потратит время на его повторное обнаружение.

Статусы:

| Статус                | Что означает                                                        |
| --------------------- | ------------------------------------------------------------------- |
| `FIXED`               | Исправлено в этом этапе, закрыто тестом                             |
| `ACCEPTED`            | Осознанно оставлено; причина указана                                |
| `NEEDS_CONFIRMATION`  | Правило не подтверждено источником — см. `docs/UNKNOWNS.json`       |
| `BLOCKED`             | Исправление упирается во внешнее ограничение                        |

Тяжесть:

| Тяжесть   | Что означает                                                          |
| --------- | --------------------------------------------------------------------- |
| `BLOCKER` | Пользователь не может выполнить задачу или теряет работу               |
| `HIGH`    | Приводит к неверному результату или потере данных при обычном действии |
| `MEDIUM`  | Мешает, но обходится; результат остаётся верным                        |
| `LOW`     | Косметика и мелкие неровности                                          |

## Что НЕ является дефектом

Разбирались и признаны правильным поведением:

- **Кнопки «Пересчитать» нет.** Все производственные результаты выводятся
  из проекта и нигде не хранятся: устаревать нечему. Кнопка обещала бы,
  что без неё данные неверны, — а это неправда.
- **Автосохранения нет.** Молчаливая запись поверх файла — это потеря
  работы, если пользователь экспериментировал. Сохранение остаётся явным
  действием, а несохранённые правки видны постоянно.
- **Адреса объектов освобождаются через 60 секунд, а не сразу.**
  Немедленный `revokeObjectURL` отменяет саму загрузку файла. Проверено
  `tests/e2e/resources.spec.ts`: на документ приходится ровно один адрес.
