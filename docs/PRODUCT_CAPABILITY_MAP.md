# Product Capability Map

PROMPT 51 §12. Что продукт умеет на коммите **`e10be44`**, версия
**0.1.0**.

Здесь только **подтверждённые** возможности: каждая строка опирается на
код и проверку. Полная сводная таблица по 60 возможностям с разбивкой по
слоям — `PRODUCT_CAPABILITY_TRUTH.md`; прослеживаемость к требованиям —
`PRODUCT_REQUIREMENT_TRACEABILITY.md`.

## Design

* Проект создаётся при открытии — без регистрации, входа и оплаты.
* Габариты изделия: ширина, высота, глубина, толщина плиты.
* Сценарий из 11 шагов ведёт от габаритов к производству.
* Отмена и повтор для всех 44 команд модели.
* Библиотека проектов: поиск, порядок, дублирование, переименование.
* Импорт и экспорт проекта одним файлом в открытом формате.

## Construction

* Корпус: боковины, крышка, дно, схема сборки.
* Секции: равные или заданной ширины, с перегородками как деталями.
* Сетка ячеек внутри секции: ряды и колонки.
* Наполнение ячейки: пусто, полки, ящики.
* Фасады: распашные двери и фасады ящиков, сторона петель, накладные и
  вкладные.
* Способ открывания: ручка с размещением или push-to-open.
* Задняя стенка: накладная или вкладная, цельная или по секциям.
* Цоколь с царгами; столешница со свесом; антресоль; фальшпанели; зазор
  до потолка.

## Materials

* Реестр материалов и назначение по ролям деталей.
* Толщина полки берётся из материала.
* Кромка по четырём сторонам детали, метраж в спецификации.
* Расхождение толщины корпуса с толщиной материала **называется**
  предупреждением, а не молчит.

## Calculations

* Геометрия из пяти этапов: `normalize → carcass → layout → fill → facades`.
* Валидация проекта: значения, ссылки, структура, толщина.
* Все производные величины **выводятся при каждом обращении** и нигде не
  хранятся — устаревшего результата не бывает, кнопки «Пересчитать» нет.

## Production

* Деталировка: размеры, материал, кромка, текстура, количество.
* Чертёж выбранной детали с масштабированием.
* Раскрой по листам: размещение, отход, процент использования,
  **неразмещённые детали названы с причиной**.
* Фурнитура: направляющие и полкодержатели посчитаны; петли и корпусной
  крепёж ждут подтверждения правила и говорят об этом.
* Спецификация: детали, фурнитура, материалы, кромка.
* Прослеживаемость: деталь в сцене ↔ позиция ↔ чертёж ↔ карта раскроя.
* Готовность к производству одним статусом.

## Persistence

* Проекты в IndexedDB браузера; в приватном режиме — память вкладки, и
  приложение об этом говорит.
* Схема версионируется, старые файлы читаются миграциями.
* Автосохранения нет **намеренно**: запись поверх сохранённого потеряла
  бы работу того, кто экспериментировал. Состояние записи и что делать
  при отказе — видно постоянно.
* Проверено цепочкой: редактор = сохранённое = перезагруженное =
  расчёт = выгруженный документ = файл проекта.

## Export

* **PDF** — производственная документация: A4 для текста, A3 для карт
  раскроя, встроенный шрифт, кириллица.
* **XLSX** — семь листов: сводка, детали, фурнитура, присадка, раскрой,
  материалы, кромка.
* Оба открываются настоящими читателями и несут те же числа, что
  показывал редактор.
* Каждый документ несёт список неподтверждённых правил — цех видит их
  вместе с цифрами.

## Visualization

* Трёхмерная сцена на собственном рендерере WebGL 2: выбор деталей,
  вращение, масштаб, изменение габаритов перетаскиванием.
* Плоская схема как равноправная альтернатива сцене.
* Планировщик помещения: стены, пол, потолок, проёмы, препятствия,
  расстановка мебели, привязка и коллизии.
* Недоступный WebGL **объясняется**, а не превращается в ошибку.

## Mobile

* Телефон и планшет: параметры листом, компактная навигация по шагам,
  цели для пальца не меньше 40 px.
* Проверено на 360, 375, 390, 430, 834 и 1440 px: горизонтального
  перебора нет ни на одном разделе.

## Reliability

* Корневая граница ошибки: непредвиденный отказ не даёт белого экрана.
* Границы вокруг четырёх разделов: отказ одного не уносит остальные.
* Ошибки вне отрисовки замечаются и показываются.
* Данные для отчёта об ошибке собираются локально, показываются целиком
  и копируются самим человеком.
* Работа без сети после первого открытия — включая экспорт.

## Explicit Limitations

Названы прямо, а не умолчаны.

| Ограничение | Статус |
| --- | --- |
| Присадка выдаёт 0 операций | правила не подтверждены (P-02) |
| Петли и корпусной крепёж не рассчитываются | правила не подтверждены (P-03) |
| Короб ящика не строится | правило не подтверждено (P-04) |
| Штанги нет в интерфейсе | правило не подтверждено (P-05) |
| Задняя стенка не делится по размеру листа | пробел продукта (P-01) |
| Вырез в цоколе не строится | частичная реализация (P-06) |
| Фасады купе, складные, подъёмные | не поддерживаются (P-07) |
| Фасад на несколько ячеек | не поддерживается |
| Произвольный контур помещения | инструмента рисования нет (P-08) |
| Экспорт CSV | не заявлен и не реализован |
| Синхронизация между устройствами | нет и не планируется: продукт локальный |
| Учётные записи, оплата, реклама, трекинг | нет; проверяется `npm run check:brand` |
| Отдельные адреса у экранов | сознательное решение |
