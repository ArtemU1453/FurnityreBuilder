### Объяснение единственного расхождения

`.b3d` хранит **4** экземпляра направляющих — по одному на каждый из
четырёх ящиков. Деталировка указывает **8**.

Доказательство, что это разница ЕДИНИЦ, а не потеря данных: все четыре
экземпляра стоят на `x = 16` — это внутренняя грань левой стенки
(`x ∈ [0, 16]`), и их `y` (115, 314, 531, 731) соответствуют четырём
ящикам. Правых экземпляров в файле нет вовсе.

**Вывод:** в модели направляющая — один объект «комплект на ящик», в
деталировке — штуки (2 на комплект). `4 × 2 = 8`. Ранее подтверждённые
«2 направляющие на ящик» этим не опровергаются, а объясняются.

## 2. FACT — восстановленная геометрия изделия

Габарит из координат: **1240 × 2100 × 403** (задняя стенка 3 мм в
`z ∈ [0, 3]`, корпус — `z ∈ [3, 403]`).

| Деталь | Коробка |
| --- | --- |
| крыша накладная | x[0…1240] y[2084…2100] z[3…403] |
| дно накладное | x[0…1240] y[0…16] z[3…403] |
| стенка левая | x[0…16] y[16…2084] z[3…403] |
| стенка правая | x[1224…1240] y[16…2084] z[3…403] |
| перегородка 1 | x[612…628] y[16…2084] z[3…403] |
| полка ×4, полка-стяжка ×4 | два отсека 596 мм, уровни y = 432, 849, 1266, 1683 |
| доп. перегородка ×8 | x = 306 (3 шт) и x = 918 (5 шт) |
| ящики ×4 | левый отсек, y ≈ 25, 224, 441, 641 |
| задняя стенка ×5 | полосы по Y, см. `B3D_PM18_PM17_EVIDENCE.md` |

Крыша и дно **накладные**: лежат поверх боковин (`y ∈ [0,16]` и
`[2084,2100]`, боковины `y ∈ [16, 2084]`). Это подтверждает названия
деталей геометрией, а не только подписью.

### Как восстановлены коробки

Ориентация локальных осей **не угадывалась**. Для каждой детали известны
положение, кватернион, толщина и размеры `L × W` из деталировки.
Перебираются обе раскладки `(L,W)`/`(W,L)` и все восемь комбинаций знаков;
принимается та коробка, которая целиком лежит в габарите изделия.

Результат: **46 из 46** деталей получили коробку. Совпадение всех
46 — само по себе проверка метода: неверная раскладка вывела бы деталь за
габарит.

### INFERENCE — закономерность

Размещены те элементы, **под которые сверлится отверстие**. Заглушки,
дюбель минификса и крабики только посчитаны.

Исключение, которое стоит отметить: «Шток рафикса» размещён (48), а
«Минификс шток (дюбель)» — нет (40). Оба — ответные части. Почему у
рафикса ответная часть имеет координаты, а у минификса нет, файл не
объясняет.

**Это объяснение, а не правило.** Оно описывает наблюдаемое в одном
файле и не переносится на другие проекты без проверки.

## 4. FACT — схемы присадки хранятся у фурнитуры

Каждое описание фурнитуры несёт отверстия в **локальных** координатах.
Примеры, прочитанные из файла дословно:

| Фурнитура | Отверстия (x, y, z; направление; радиус; глубина) |
| --- | --- |
| Минификс D15 | (0, −8, 0) dir(−1,0,0) **r 2.5, гл. 13**; (0, −8, 0) dir(1,0,0) **r 4, гл. 28**; (34, 0, 0) dir(0,−1,0) **r 7.5, гл. 13** |
| Рафикс | (0, −8, 0) dir(−1,0,0) **r 2.5, гл. 13**; (9.5, 0, 0) dir(0,−1,0) **r 10, гл. 12.5** |

Радиус 7.5 у минификса → Ø15, что сходится с названием «Минификс **D15**».
Сходимость названия и геометрии — независимая проверка разбора.

**Это данные присадки** (`T-DRILL-*`). В PROMPT 66 они только
зафиксированы: §E запрещает реализовывать присадку, и координаты
локальные — перевод в мировые требует отдельной работы.
