## 1. ЧТО ПОДТВЕРЖДЕНО

### 1.1 Форматы выгрузки — `CONFIRMED`

Источник: сниппет поисковой выдачи по `privetmaket.ru/raspil` и `privetmaket.ru/`.

Референс отдаёт комплект производственных файлов:

1. PDF-чертёж со схемой изделия, размерами и деталировкой;
2. схема присадки (сверловки);
3. карта раскроя;
4. XLS-файл с деталями, фурнитурой и крепежом;
5. Базис-модель (файл для САПР «Базис-Мебельщик»).

**Вывод для нас.** Набор выходных данных — это и есть ядро ценности продукта:
пользователь получает не картинку, а комплект для производства. Пункты 1–4 реализуемы
локально в браузере. Пункт 5 — проприетарный бинарный формат стороннего САПР,
см. `FEATURE_MATRIX.md` (ID `EXP-06`, статус `OUT_OF_SCOPE`).

### 1.2 Материал — `CONFIRMED`

Работа с ЛДСП разной толщины, включая 16 мм. Также упоминаются МДФ и фанера
(страница услуги распила).

### 1.3 Ограничение длины полки — `CONFIRMED`

Референс публикует отдельную статью «Рекомендации по длине/ширине полок и допустимой
нагрузке». Из сниппета: для глубины конструкции 300–400 мм рекомендуемая максимальная
длина полки из ЛДСП 16 мм — **до 600 мм**.

**Вывод для нас.** Это правило валидации, а не жёсткое ограничение: должно давать
предупреждение (`warning`), а не блокировать проект. См. `VAL-SHELF-SPAN` в
`FEATURE_MATRIX.md`.

### 1.4 Поля ввода габаритов — `CONFIRMED`

Интерфейс содержит поля Ширина / Высота / Глубина в миллиметрах.
Числовые границы этих полей — `UNKNOWN` (см. §2.1).

### 1.5 Продуктовая модель — `CONFIRMED`

Конструктор бесплатный, позволяет скачать чертежи и изготовить изделие самостоятельно;
изготовление на заказ — отдельная платная услуга сайта.

**Вывод для нас.** Наш продукт берёт только бесплатную проектную часть.
Никакой коммерческой воронки, заказа, корзины, форм захвата контактов.

### 2.1 Габариты

| Параметр | Статус | Значение | Тест для установления |
| --- | --- | --- | --- |
| Ширина W | `UNKNOWN` | границы неизвестны | T-DIM-01 |

| Глубина D | `UNKNOWN` | границы неизвестны | T-DIM-01 |
| Толщина T | `INDUSTRY` | 16 мм по умолчанию; ряд 10/16/18/22 | T-DIM-02 |

**Тесты.**

- **T-DIM-01.** Открыть конструктор, зафиксировать значения полей при загрузке.

- **T-DIM-02.** Найти селектор толщины материала; перечислить опции.

- **T-DIM-03.** Ввести `1001` при W=1000; проверить, принимается ли значение,
  не кратное 10.
- **T-DIM-04.** Построить изделие с 3 полками, затем увеличить H на 300 мм.
  Зафиксировать: полки сохранили абсолютные отметки, доли высоты, или
  перераспределились равномерно. Это определяющий вопрос для нашей модели ячеек.
- **T-DIM-05.** Ввести значение заведомо больше max; зафиксировать UI-реакцию.

### 2.2 Каркас

| Элемент | Статус | Тест |
| --- | --- | --- |
| Левая / правая стенка | `UNKNOWN` — размер зависит от схемы сборки | T-CAR-01 |
| Верх | `UNKNOWN` — накладной или вкладной | T-CAR-01 |
| Низ | `UNKNOWN` — накладной или вкладной | T-CAR-01 |
| Перегородки (стойки) | `UNKNOWN` — на всю внутреннюю высоту или по секциям | T-CAR-02 |
| Полки | `UNKNOWN` — съёмные / стационарные / оба типа | T-CAR-03 |
| Задняя стенка | `UNKNOWN` — накладная или в паз; толщина | T-CAR-04 |
| Основание (цоколь / ножки) | `UNKNOWN` — есть ли вообще | T-CAR-05 |
| Верхняя часть (антресоль) | `UNKNOWN` | T-CAR-05 |
| Столешница | `UNKNOWN` — свесы и толщина | T-CAR-06 |

**Тесты.**

- **T-CAR-01 (ключевой).** Задать ровно W=1000, H=2000, D=500, T=16.
  Выгрузить деталировку. Сопоставить размеры:
  - боковина `2000×500` **и** верх/низ `968×500` → схема «стенки внешние»;
  - боковина `1968×500` **и** верх/низ `1000×500` → схема «горизонтали внешние»;
  - боковина `1984×500` + верх `1000×500` + низ `968×500` → смешанная.
  Один этот тест снимает большинство неопределённостей геометрии.
- **T-CAR-02.** Добавить перегородку, выгрузить деталировку. Высота детали
  перегородки покажет, идёт ли она на всю внутреннюю высоту.
- **T-CAR-03.** Проверить, есть ли переключатель типа полки; сверить наличие
  полкодержателей в спецификации фурнитуры.
- **T-CAR-04.** Сравнить габаритную глубину и глубину боковины в деталировке.
  Разница = толщина задней стенки → значит задняя стенка входит в габарит.
  Размер детали задней стенки покажет накладной монтаж (`W×H`) или паз.
- **T-CAR-05.** Проверить наличие соответствующих опций в UI.
- **T-CAR-06.** При наличии столешницы сравнить её ширину/глубину с габаритом
  корпуса; разница даёт свесы.

## 4. ПОЧЕМУ ЭТО НЕ БЛОКИРУЕТ ПРОЕКТ

Неопределённость касается **конвенций конкретного референса**, а не математики.
Геометрия корпусной мебели выводится из первых принципов: детали — прямоугольные
параллелепипеды, стыкующиеся по плоскостям; неизвестна только схема стыка.

Поэтому геометрическое ядро проектируется **параметризованным по схеме сборки**
(`ConstructionScheme`, см. `DATA_MODEL.md` §4 и `ARCHITECTURE.md` §5):

- поддерживаются все реалистичные варианты стыка;
- значение по умолчанию берётся из отраслевой практики и **явно помечено** как
  предположение в коде (`// ASSUMPTION:` + ссылка на ID теста);
- когда тест будет проведён, меняется одна константа конфигурации, а не алгоритм.

Это единственный честный способ двигаться дальше без выдумывания чисел.
