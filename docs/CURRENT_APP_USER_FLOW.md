# Current App User Flow

PROMPT 52 §10. Фактический сценарий **текущего** приложения на коммите
`a94cc6a`.

Пройден целиком на собранном приложении, а не восстановлен по коду.

## Основной путь

```
Открыть приложение
   ↓  проект создаётся сам — 5 деталей до первого действия
Шаг «Размеры»: ширина, высота, глубина, толщина
   ↓  каждое поле сразу меняет сцену и расчёт
Шаг «Корпус»: схема сборки, задняя стенка, цоколь, надстройки
   ↓
Шаг «Секции»: число секций, ширины
   ↓  «Применить секций: N» — черновик применяется кнопкой
Шаг «Ячейки»: ряды, колонки, полок в каждой
   ↓  «Разделить «имя отделения» на N×M» — делит ВЫБРАННОЕ отделение
   ↓  и не трогает секции (PROMPT 55). Пересборка всего изделия —
   ↓  отдельное действие за раскрытием, с предупреждением
Шаг «Полки»: полки выбранной ячейки
   ↓
Шаг «Наполнение»: пусто / полки / ящики для выбранной ячейки
   ↓
Шаг «Фасады»: дверь на ячейку, сторона петель, накладной/вкладной,
                способ открывания
   ↓
Шаг «Материалы»: материалы по ролям, кромка
   ↓
Шаг «Конструкция»: схема сборки, допуски, политика кромки
   ↓
Шаг «Проверка» → экран «Производство», раздел «Сводка»
   ↓
Шаг «Производство»: детали, чертежи, присадка, раскрой,
                    фурнитура, спецификация, документы
   ↓
«Скачать PDF» / «Скачать XLSX»
```

## Ключевые свойства этой модели

| Свойство | Как устроено |
| --- | --- |
| **Ведение по шагам** | лестница из 11 шагов слева; шаг меняет содержимое панели, а не экран |
| **Черновик и применение** | «Секций» и «Сетка» набираются полем и применяются кнопкой; габариты применяются немедленно |
| **Выбор объекта** | щелчок по детали в сцене или на схеме; выбранное появляется в правой панели |
| **Выбор ячейки** | ячейка выбирается на холсте; панели шагов «Полки», «Наполнение», «Фасады» действуют на выбранную |
| **Пересчёт** | автоматический: производные величины не хранятся, кнопки «Пересчитать» нет |
| **Сохранение** | явное, кнопкой; автосохранения нет намеренно |
| **Финальное действие** | выгрузка документов, а не заказ: корзины и оплаты в продукте нет |

## Побочные пути

```
Библиотека → открыть другой проект / дублировать / переименовать /
             выгрузить файлом / загрузить файл
Помещение  → создать комнату → расставить изделия → проёмы, препятствия
Ошибка     → объяснение + безопасное действие + данные для отчёта
Без сети   → всё вышеперечисленное, включая экспорт
```

## Чем этот сценарий ЗАКАНЧИВАЕТСЯ

Выгрузкой производственных документов и сохранением проекта в браузере.

Коммерческого завершения — корзины, заказа, оплаты, отправки на
производство — в продукте **нет**, и это продуктовое решение, а не
незавершённость: приложение бесплатное, без регистрации и без серверной
части.
