# Current App Screen Map

PROMPT 52 §10. Карта экранов **текущего** приложения на коммите
`a94cc6a`, версия 0.1.0.

Измерено, а не описано: геометрия зон снята со собранного приложения
(`npm run build` + `npm run preview`) в окне 1440 × 900 средствами
браузера. Числа ниже — реальные координаты и размеры в пикселях.

## Общая рамка приложения

Одинакова на всех четырёх экранах.

```
┌──────────────────────────────────────────────── 1440 ────┐
│ Шапка проекта              y=0   h=49                    │  имя, габарит,
│                                                          │  состояние записи,
│                                                          │  отмена/повтор/сохранить
├──────────────────────────────────────────────────────────┤
│ Разделы приложения         y=49  h=51                    │  4 радио-кнопки
├──────────────────────────────────────────────────────────┤
│                                                          │
│ main                       y=100 h=765                   │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ Состояние проекта          y=865 h=35                    │  проблемы, готовность,
└──────────────────────────────────────────────────────────┘  версия
```

**Модель навигации — плоская:** четыре равноправных раздела в одной
полосе, переключаются радио-группой «Разделы приложения». Вложенной
навигации, вкладок второго уровня и адресов у экранов нет.

## Экран 01 — Конструктор

**Назначение.** Задать изделие: габариты, структуру, наполнение, фасады,
материалы.

| Зона | Координаты | Что содержит |
| --- | --- | --- |
| Левая панель | x=16 y=112 · **320 × 672** | «Этапы конструктора» — лестница из 11 шагов **плюс** панель текущего шага под ней |
| Центр | между 336 и 1124 · ≈ **770 × 672** | холст: трёхмерная сцена или плоская схема |
| Правая панель | x=1124 y=112 · **300 × 192** | «Свойства объекта» — инспектор выбранной детали |
| Нижняя полоса | y=865 · 1440 × 35 | состояние проекта |

**Доминирование рабочей области:** холст занимает ≈ 53 % ширины;
левая панель 22 %, правая 21 %.

**Что меняется при взаимодействии.** Выбор шага в лестнице меняет
**содержимое левой панели** — сам холст и правая панель остаются.
Выбор детали на холсте наполняет правую панель.

## Шаги конструктора

Одиннадцать, строго по порядку, плюс «Назад» и «Далее»:

```
Размеры → Корпус → Секции → Ячейки → Полки → Наполнение →
Фасады → Материалы → Конструкция → Проверка → Производство
```

Шаг — это **смена содержимого левой панели**, а не смена экрана.
«Проверка» и «Производство» переводят на экран 02.

## Состояние-зависимые элементы

| Появляется | При условии |
| --- | --- |
| «Свойства объекта» (правая панель) | выбрана деталь на холсте |
| Панель ячейки на шаге «Ячейки» | выбрана ячейка; иначе — «Ячейка не выбрана» с подсказкой |
| Диалог «Сетка заменит внутреннее устройство» | применение сетки, когда есть что терять |
| Полоса «Доступна новая версия» | воркер обнаружил обновление |
| Полоса «Приложение столкнулось с непредвиденной ошибкой» | необработанное исключение |
| Лист параметров | ширина ≤ 767 px: панели превращаются в лист снизу |

## Мобильная раскладка

При ширине ≤ 767 px левая панель исчезает: параметры открываются
**листом снизу** по кнопке с именем текущего шага, холст занимает экран,
шаги идут компактной полосой. Проверено на 360, 375, 390, 430 px —
горизонтального перебора нет.
