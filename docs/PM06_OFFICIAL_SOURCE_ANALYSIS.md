## 3. Ответы на вопросы §9

| Что требовалось установить | Найдено? |
| --- | --- |
| модели петель | **нет** |
| тип петли | **частично**: накладные/вкладные фасады различаются, петли для стекла выделены отдельно; четырёхшарнирность в официальном тексте не встретилась |
| алгоритм количества петель | **НЕТ** |
| размерные пороги | **НЕТ** |
| расчёт массы фасада | **НЕТ** |
| координаты установки | **НЕТ** |

Единственное число во всей области — **5 мм** вертикальной регулировки
(H-2). Это диапазон регулировки готовой петли, а не проектная величина:
из него не следует ни количество, ни присадка.

Единственный найденный «порог» — **35×35 см** — относится к **стеклянным**
дверям (H-3) и является рекомендацией по размеру стекла. Переносить его
на фасад из ЛДСП было бы ровно тем, что запрещено §11.

## 5. Что доказано и что не доказано

| | |
| --- | --- |
| **ЧТО ДОКАЗЫВАЕТ** | что возможность выбора петель в конструкторе существует; что петля регулируется в трёх плоскостях; что вертикальная регулировка около 5 мм |
| **ЧТО НЕ ДОКАЗЫВАЕТ** | сколько петель ставится на створку; от чего это зависит; какая петля; где сверлить |
| **СЛЕДСТВИЕ ДЛЯ РЕАЛИЗАЦИИ** | `hingeRule` продолжает возвращать **0 петель**. `T-HW-01` и `T-DOOR-05` остаются `unknown` |

Возможность в интерфейсе — это **A (CAPABILITY)** по классификации §6.
Только **D (UNIVERSAL RULE)** разрешает алгоритм. Расстояние между ними
здесь максимальное из всех четырёх разбираемых областей.
