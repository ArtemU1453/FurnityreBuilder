## 1. ЧТО ПРОВЕРЯЛОСЬ

Продукт должен быть полностью самостоятельным: ни одного следа
исследовательского референса в пользовательской части, ни одной зависимости
от его инфраструктуры.

## 4. ПРАВИЛА, ОБЯЗАТЕЛЬНЫЕ К СОБЛЮДЕНИЮ

### 4.1 Идентичность продукта

- **Рабочее имя:** Furniture Builder — нейтральное, описательное,
  не отсылает ни к одному существующему сервису.
- Иконка и favicon рисуются с нуля.
- Тон интерфейса — инструментальный, без маркетинга.

### 4.2 Метаданные (при создании `index.html`)

```html
<title>Furniture Builder — конструктор корпусной мебели</title>
<meta name="description" content="Бесплатный онлайн-конструктор корпусной мебели: габариты, секции, наполнение, деталировка, раскрой и экспорт. Без регистрации, данные хранятся локально.">
<meta property="og:title" content="Furniture Builder">
<meta property="og:description" content="Конструктор корпусной мебели в браузере.">
```

Запрещено упоминать сторонний сервис в любом метаполе.

### 4.3 Метаданные пакета

`name`, `description`, `author`, `homepage`, `repository` не содержат ссылок
на сторонний сервис. `license` — открытая (MIT), что соответствует
бесплатному продукту без платных функций.

### 4.4 Сетевая политика

Правило: **приложение не выполняет ни одного сетевого запроса после загрузки.**

Проверяется автоматически (этап 33):

```ts
// e2e: перехват любого запроса за пределы origin — падение теста
page.on('request', (r) => {
  if (new URL(r.url()).origin !== base) throw new Error(`Внешний запрос: ${r.url()}`);
});
```

Дополнительно — Content-Security-Policy без внешних источников:

```
default-src 'self'; img-src 'self' data: blob:; font-src 'self';
script-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self';
frame-src 'none'; object-src 'none'; base-uri 'none'
```

`frame-src 'none'` технически исключает iframe на референс.

### 4.5 Ресурсы

| Тип | Правило |
| --- | --- |
| Иконки | собственные SVG, инлайн |
| Шрифты интерфейса | системные |
| Шрифт для PDF | свободная лицензия (SIL OFL / Apache 2.0), файл в репозитории, лицензия рядом |
| Изображения | не используются; иллюстрации — векторные схемы, генерируемые из модели |
| Материалы и декоры | вводит пользователь; брендовых каталогов нет |

### 4.6 Запрещённое содержимое (сверх брендинга)

Продукт не содержит: регистрации, авторизации, подписок, платных функций,
рекламы, промо-блоков, форм захвата контактов, аналитики, трекеров,
обязательных внешних сервисов.

### Два уточнения, появившихся при автоматизации

**1. Ссылка на собственный исследовательский документ.** В `README.md`
и в реестре предположений встречается путь `docs/PRIVETMAKET_FUNCTIONAL_SPEC.md`.
Имя файла задано требованиями первого этапа и не может быть изменено.
Ссылка на файл нашей же документации разработчика — не упоминание сервиса
в продукте, и проверка допускает ровно это вхождение. При этом
**в собранном артефакте исключений нет**: `dist/` проверяется без послаблений,
и упоминаний там не найдено (комментарии до сборки не доживают).

**2. URL внутри JavaScript-бандла.** Минифицированный React содержит ссылки
на собственную документацию в текстах сообщений об ошибках. Это строки,
а не обращения к сети. Поэтому проверка внешних источников в `dist/`
применяется к разметке и стилям — местам, где загрузки объявляются, —
а отсутствие реальных запросов доказывает E2E-тест «приложение не выполняет
ни одного внешнего запроса». Это более сильная гарантия, чем поиск подстрок.

## 8. ГРАНИЦА ДОБРОСОВЕСТНОГО ИСПОЛЬЗОВАНИЯ

**Заимствовано (правомерно):**
идеи функциональности, пользовательские сценарии, отраслевая математика
корпусной мебели, состав производственных выгрузок, UX-паттерны.
Всё это — либо факты, либо общеотраслевые знания, не охраняемые авторским правом.

**Не заимствовано:**
исходный код, разметка, стили, скрипты, изображения, шрифты, иконки, тексты,
брендинг, названия, компоновка экранов, цветовая схема, каталоги материалов,
серверная инфраструктура, API.

Реализация — полностью собственная, от доменной модели до последнего пикселя.
