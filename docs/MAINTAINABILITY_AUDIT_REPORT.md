## Documentation Duplication

**PARTIAL — и это осознанное состояние, а не недосмотр.**

Дублирования инструкций нет: у каждого процесса один канонический
документ, остальные ссылаются.

| Процесс | Канонический источник |
| --- | --- |
| Запуск, сборка, команды | `OPERATIONS.md` (указатель), README (введение) |
| Архитектура | `ARCHITECTURE.md` |
| Правила расчёта | `CALCULATION_RULES.md` → восемь предметных документов |
| Хранение | `PROJECT_PERSISTENCE.md` |
| Тесты | `TESTING_STRATEGY.md` |
| Ворота | `CI_QUALITY_GATES.md` |
| Выпуск | `RELEASE_PROCESS.md` |
| Выкладка | `DEPLOYMENT.md`, `GITHUB_PAGES_DEPLOYMENT.md` |

Что остаётся: **103 документа — это много**, и часть предметных
документов (`EDITOR_*`, `PRODUCTION_*`, `3D_*`) пересекается по темам.
Сливать их в этом PROMPT не стали: это переписывание содержания, а не
устранение дублирования инструкций, и без предметной сверки каждого
слияния оно потеряло бы детали.
