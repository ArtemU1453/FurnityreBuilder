## Still blocked — чего конкретно не хватает

### `PM-18` — корпусный крепёж

| Нужно | Зачем |
| --- | --- |
| Количество крепежа на стык **или** шаг по длине стыка | без этого позиция не выдаётся |
| Зависит ли количество от длины стыка | от ответа зависит, нужно ли расширять `CarcassJoint` полем длины |
| Различаются ли виды стыка | сейчас все восемь считались бы одинаково |
| Соответствие `JointType` → позиция реестра | модель знает четыре типа, правило печатает конфирмат независимо от схемы |

Источник: техкарта сборки корпусной мебели либо монтажная инструкция
стяжки выбранного типа.

### `PM-06` — петли

| Нужно | Зачем |
| --- | --- |
| Таблица количества по параметрам створки | основной блокер |
| Какие параметры в неё входят | если нужна масса — **у `Material` нет плотности**, потребуется второй источник |
| К какому семейству петель таблица относится | одну таблицу нельзя применять ко всем петлям |

Источник: каталог производителя петель.

### `PM-17` — крепёж задней стенки

| Нужно | Зачем |
| --- | --- |
| Шаг крепления по периметру | основной блокер |
| Крепится ли стенка к внутренним вертикалям | периметр занижает контур на **35 %** в контрольном изделии |
| Поведение при монтаже в паз | для стенки в пазу «периметр × шаг» даёт заведомо неверное число |
| Правила по углам и различие сторон | точность |

Источник: тот же документ, что для `PM-18`, раздел задней стенки.

Предыдущая очередь предполагала, что `PM-18`, `PM-06` и `PM-17`
закроются, «вероятно, одним документом»

| Группа | Правила | Источник |
| --- | --- | --- |
| **Группа 1** | `PM-18` + `PM-17` | один документ: техкарта сборки корпусной мебели |
| **Группа 2** | `PM-06` | другой документ и другая отрасль: каталог производителя петель |

Группы независимы. Получение одного не разблокирует другую.

## Присадка

Отдельный разбор — `DRILLING_PIPELINE_BLOCKER_ANALYSIS.md`. Кратко: семь
правил, ноль операций, **два разных блокера**. Пять правил из семи ждут
только параметров отверстий; настоящая нехватка конструктивной связи — у
двух (полкодержатели, направляющие).

Присадка корпусного крепежа и задней стенки — **зависимый этап** после
`PM-18`/`PM-17`. Остальное — независимые задачи со своими источниками.
