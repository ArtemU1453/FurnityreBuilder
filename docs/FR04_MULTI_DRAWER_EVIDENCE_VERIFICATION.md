## 3. Что проверяют новые тесты

`tests/unit/research/b3d-drawers.test.ts`, 6 проверок. Все зависят от
настоящего файла и **пропускаются** без `B3D_FIXTURE`: проектный файл
заказчика в репозиторий не кладётся.

| Проверка | Что сторожит |
| --- | --- |
| четыре ящика, у каждого пять деталей | базовое выделение |
| группировка по координате, а не по имени | имя несёт номер ОТСЕКА; по имени вышло бы два ящика вместо четырёх |
| у каждого своя направляющая и своя ручка | привязка фурнитуры к ящику, а не к группе |
| все четыре размерно идентичны | **ключевой вывод §4**: это повторения, а не образцы |
| направляющая на середине боковины | отношение 89.5 / 179 на всех четырёх |
| фасады одинаковы при разных отсеках | **шаги 199 и 200** — тот самый лишний миллиметр |

Последняя проверка закрепляет именно то, что позволило исключить
формулу: если однажды фасады начнут различаться вместе с отсеком, тест
упадёт, и вывод придётся пересматривать.

**Тестов на геометрию ящика не добавлено**: реализации нет, подтверждённых
правил нет, проверять нечего.

## 7. Чего проверка НЕ подтверждает

| Что | Почему |
| --- | --- |
| Одинаковость схемы крепежа у четырёх ящиков | привязка разрешается до имени детали, а имя покрывает два ящика; делимость итогов нацело — вывод, а не измерение |
| Любая формула размеров | из четырёх кандидатов по высоте исключён один, осталось три неразличимых |
| Универсальность зазора 13 мм | один размерный случай, четыре повторения |
| Универсальность «направляющая по середине» | одна высота боковины |
