## Core Domain Consistency

**PASS.**

Цепочка «параметры → правила → модель → детали → производство»
проверена сквозным прогоном на production-сборке: изменение габарита
доходит до сцены, до деталировки, до раскроя и до выгруженного
документа. Ни NaN, ни нулевых размеров, ни расхождения количеств.

Правила, которые **не подтверждены**, названы по идентификаторам и не
объявлены правильными: `T-DRILL-01…05`, `T-HW-03`, `T-HW-07`,
`T-DOOR-05`, `T-DRW-02`, `T-EDG-02`, `T-EDG-03`, `T-CUT-01…03` и другие
— всего 21. По каждому продукт выдаёт предупреждение, оно доходит до
спецификации и поднимает статус готовности.

**DOMAIN RULE REQUIRES VERIFICATION** — для всех перечисленных.

**PASS.** Проверена полная цепочка из пяти состояний:

```
редактор = сохранённое = перезагруженное = расчёт = выгруженный документ
                                                  = файл проекта
```

Габариты 1830 × 2260 × 580 совпали во всех пяти; число деталей — в
четырёх, где оно есть.

## Export Consistency

**PASS.** XLSX открыт `exceljs`: 7 листов, габариты и число деталей

## Release Claim Consistency

**PARTIAL — найдена одна неточность, исправлена.**

`FINAL_RELEASE_REPORT.md` в перечне «что входит в выпуск» называл
присадку и фурнитуру без оговорки. Прослеживаемость этого не
подтверждает: присадка даёт **0 операций**, фурнитура не считает петли и
корпусной крепёж.

Скрывать не стали: формулировка исправлена, а сам факт записан здесь и в
`PRODUCT_GAP_REGISTER.md`. Решение о стабильном выпуске не изменилось —
ни один пробел не является release blocker.

Остальные документы проверены на то же: `README.md`,
`RELEASE_NOTES.md` и `PRODUCT_CAPABILITY_TRUTH.md` не заявляют больше
подтверждённого.
