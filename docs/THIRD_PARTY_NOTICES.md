# Сторонние компоненты и их лицензии

PROMPT 32 §16. Перечислено то, что действительно попадает к пользователю
или используется при сборке. Список получен из `package-lock.json`, а не
составлен по памяти: команда, которой он проверяется, приведена в конце.

Собственный код проекта распространяется по лицензии MIT — см.
[`../LICENSE`](../LICENSE). Поле `license` в `package.json` объявляет ту же
лицензию; второго объявления в проекте нет.

## 2. Шрифты

| Материал | Лицензия | Где лежит |
| --- | --- | --- |
| Liberation Sans Regular | SIL Open Font License 1.1 | `public/fonts/LiberationSans-Regular.ttf` |

Шрифт нужен для PDF: стандартные 14 шрифтов PDF не содержат кириллицы, а
производственная документация на русском без неё невозможна. Он лежит в
репозитории и отдаётся тем же сервером, что и приложение — экспорт обязан
работать без единого стороннего запроса.

Уведомление о лицензии (`public/fonts/README.md`) выкладывается вместе со
шрифтом намеренно: SIL OFL требует, чтобы лицензия сопровождала файл.

В интерфейсе используются **системные** шрифты (`-apple-system`,
`Segoe UI`, `Roboto` и далее по цепочке). Ни один шрифт не загружается из
сети — ни с Google Fonts, ни с какого-либо CDN; это проверяет
`npm run check:brand`.

## 3. Значки и фирменный знак

Все значки нарисованы для этого проекта:

| Файл | Что это |
| --- | --- |
| `public/favicon.svg` | знак приложения, исходная форма |
| `public/icon-192.png`, `icon-512.png` | значки для манифеста |
| `public/icon-maskable-512.png` | значок с полем безопасности для Android |

PNG собираются из той же геометрии генератором
`scripts/build-icons.mjs` — чтобы формы не разъезжались. Никаких наборов
значков, шаблонов и материалов сторонних сервисов в продукте нет.

## 5. Чего в продукте нет

Проверено `npm run check:brand` (364 файла) и `npm run check:release`:

- ни одного обращения к стороннему домену;
- ни одного шрифта, значка или скрипта с CDN;
- ни одной системы аналитики и ни одного счётчика;
- ни одного `iframe` и ни одного встроенного виджета;
- ни одной строки чужого исходного кода и ни одного чужого материала.

## 6. Как проверить список

```bash
node -e "
const lock = JSON.parse(require('fs').readFileSync('package-lock.json','utf8'));
for (const [name, meta] of Object.entries(lock.packages)) {
  if (!name.startsWith('node_modules/') || meta.dev) continue;
  console.log(name.replace(/^node_modules\//,''), meta.version, meta.license);
}
"
```

Команда печатает ровно те пакеты, которые попадают в runtime, с версией и
лицензией. Расхождение с таблицей §1 означает, что таблица устарела.
