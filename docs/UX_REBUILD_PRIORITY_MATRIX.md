## Как читать оценки пересчёта

| Измерение | Что означает | Шкала |
| --- | --- | --- |
| **Journey Impact** | насколько мешает довести изделие до пригодных производственных данных | `блокирует` → `искажает результат` → `замедляет` → `не мешает` |
| **Frequency** | как часто обычный человек на это натыкается | `всегда` — на каждом проходе пути; `часто` — при обычном сценарии; `иногда` — при отдельном действии; `редко` |
| **Discoverability** | насколько трудно догадаться до верного действия | `невозможно без подсказки` → `надо угадать` → `находится` → `названо` |
| **Error Cost** | во что обходится неверный выбор | `потеря работы` → `неверное представление о результате` → `лишний шаг` → `нет` |
| **Production Impact** | влияние на пригодность производственного результата | `делает непригодным` → `затрудняет чтение` → `нет` |
| **Dependency** | разблокирует ли исправление другие | `да, какие` / `нет` |
| **Current Evidence** | сила сегодняшнего свидетельства | `измерено` — число снято скриптом; `наблюдено` — строка скопирована из DOM; `качественно` |

Порядок — по **улучшению понятности постройки мебели на одно осмысленное
изменение продукта**, а не по цене. Дорогое наблюдение может стоять выше
дешёвого.

## Как читать

| Колонка | Что означает |
| --- | --- |
| Класс | Тяжесть по шкале карты трения: `P0` … `P4` |
| Влияние | Скольких требований идеального пути касается |

## Порядок в одну строку

**Сначала — чтобы работало то, что приложение само обещает** (ярус 1).
**Потом — чтобы ничего не терялось и всё называлось по-человечески**
(ярус 2). **Потом — чтобы путь был один** (ярус 3). Начало пути и
плотность — после, потому что они стоят дороже и мешают меньше.
