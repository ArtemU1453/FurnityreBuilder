# Furniture Builder

Бесплатный онлайн-конструктор корпусной мебели.

Проектирование шкафов, стеллажей, тумб и комодов по индивидуальным размерам
с расчётом конструкции и получением производственных данных: деталировки,
спецификации фурнитуры, кромки, карты раскроя и чертежей.

## Принципы

- полностью бесплатно;
- без регистрации и авторизации;
- без подписок и платных функций;
- без рекламы и трекинга;
- без обязательных внешних сервисов — после загрузки приложение автономно;
- проекты хранятся локально в браузере;
- импорт и экспорт проектов в открытом формате.

Данные не покидают устройство пользователя: серверной части у продукта нет.

## Состояние

**Этап проектирования.** Кода приложения пока нет — репозиторий содержит
техническую спецификацию, архитектуру, доменную модель, design system,
motion system и план разработки.
