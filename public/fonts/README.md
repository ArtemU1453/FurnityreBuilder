# Шрифт для PDF

`LiberationSans-Regular.ttf` — Liberation Sans, лицензия SIL Open Font
License 1.1. Шрифт лежит В РЕПОЗИТОРИИ и отдаётся тем же сервером, что и
приложение: экспорт PDF обязан работать без единого стороннего запроса
(`docs/BRAND_INDEPENDENCE_AUDIT.md` §4.4). Загрузка шрифта из сети —
внешняя зависимость, даже если это «бесплатный CDN».

Почему именно он: стандартные 14 шрифтов PDF не содержат кириллицы, а
производственная документация на русском без неё невозможна. Liberation
Sans содержит кириллицу, метрически совместим с распространёнными
гарнитурами и свободно распространяется.

Шрифт встраивается в PDF подмножеством (subset) — в файл попадают только
использованные глифы.
